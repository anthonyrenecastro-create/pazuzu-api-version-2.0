# S054 — No self-consistency check within consensus fan-out

- **Audit ID:** S054 (source issue #54)
- **Title:** No self-consistency check within consensus fan-out
- **Classification:** [ALG]
- **Severity:** medium
- **Severity rationale:** Branches can agree with each other while each contradicts itself.

## Original defect description
Consensus fan-out lacks a 'self-consistency' check (generations must agree with themselves, not just each other).

## Affected subsystem
S4 Swarm Agreement

## Root cause
Agreement was defined only pairwise across branches.

## Proposed correction
Add per-branch self-consistency scoring in stations/s04_swarm/agreement.py: each branch is scored on internal coherence (entailment of its own claims) before inter-branch medoid selection; incoherent branches are down-weighted.

## Implementation files
- `stations/s04_swarm/agreement.py`

## Verification method
pytest tests/unit/test_s04.py::test_self_consistency_downweights_incoherent

## Test identifier
tests/unit/test_s04.py::test_self_consistency_downweights_incoherent

## Status
implemented_unverified

## Status justification
Self-consistency layer is designed; not implemented or tested. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
The coherence scorer is itself an LLM judgment and inherits miscalibration (see issue 35).
