# S038 — min(axes) >= 0.75 strict conjunction is brittle

- **Audit ID:** S038 (source issue #38)
- **Title:** min(axes) >= 0.75 strict conjunction is brittle
- **Classification:** [MTH]
- **Severity:** medium
- **Severity rationale:** A single 0.74 axis vetoes an otherwise perfect output, inflating false rejects.

## Original defect description
min(axes) >= 0.75 is a strict intersection (conjunction). If one axis is 0.74 and the others are 1.0, it fails. A weighted linear combination or Pareto front is more robust.

## Affected subsystem
S3 Dual Ward

## Root cause
Conjunction was chosen for simplicity, not for decision quality.

## Proposed correction
Replace with a calibrated weighted rule in stations/s03_dual_ward/agreement.py: weighted combination with per-axis veto floors (hard fail only below a low floor, e.g., 0.4); weights fit on labeled data, documented in config/thresholds.yaml.

## Implementation files
- `stations/s03_dual_ward/agreement.py`
- `config/thresholds.yaml`

## Verification method
pytest tests/unit/test_s03.py::test_weighted_rule_beats_strict_conjunction

## Status justification
Weighted rule is specified; weights are unfitted and no test has run. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Weights fit on biased labels could systematically underweight a critical axis.
