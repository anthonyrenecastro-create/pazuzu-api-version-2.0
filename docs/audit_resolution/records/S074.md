# S074 — Sliding entropy window is fixed size regardless of generation type

- **Audit ID:** S074 (source issue #74)
- **Title:** Sliding entropy window is fixed size regardless of generation type
- **Classification:** [ALG]
- **Severity:** low
- **Severity rationale:** Suboptimal window sizing; a tuning issue rather than a correctness defect.

## Original defect description
The sliding window for entropy is fixed size; long creative generations will have different optimal windows than short factual ones.

## Affected subsystem
S6 Thermodynamic Brake

## Root cause
One window size was chosen for all generation regimes.

## Proposed correction
Make the window adaptive in stations/s06_brake/controller.py: scale with expected generation length (from the request profile), bounded in config/sampling.yaml.

## Implementation files
- `stations/s06_brake/controller.py`
- `config/sampling.yaml`

## Verification method

## Test identifier

## Status
scheduled

## Residual risk
