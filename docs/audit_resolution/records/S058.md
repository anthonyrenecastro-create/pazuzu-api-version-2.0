# S058 — Curl |∇×v| is undefined for embeddings with d >> 3

- **Audit ID:** S058 (source issue #58)
- **Title:** Curl |∇×v| is undefined for embeddings with d >> 3
- **Classification:** [MTH]
- **Severity:** high
- **Severity rationale:** The cross product does not exist in dimensions other than 3 (and 7); the core formalism is mathematically invalid.

## Original defect description
Curl |∇×v| is only defined in 3D. Embeddings have d >> 3, where the cross product is undefined. This is a fatal mathematical error in the core formalism.

## Affected subsystem
S5 Vector Current

## Root cause
Vector-calculus operators were borrowed from fluid dynamics without checking their domain of definition.

## Proposed correction
Remove the 3D curl operator entirely from stations/s05_vector_current/station.py and stations/s05_vector_current/trajectory.py. Replace its role (detecting rotational/cyclic drift) with a well-defined alternative: the skew-symmetric part of the local Jacobian estimated in the reduced subspace, or circulation computed on 2D projections. No curl symbol or cross product remains in the formalism.

- `stations/s05_vector_current/station.py`
- `stations/s05_vector_current/trajectory.py`
- `docs/formalism.md`
