# S066 — GET /v1/field exposes raw diagnostics with no auth scope

- **Audit ID:** S066 (source issue #66)
- **Title:** GET /v1/field exposes raw diagnostics with no auth scope
- **Classification:** [API]
- **Severity:** high
- **Severity rationale:** Unauthenticated internal diagnostics are an information-disclosure vulnerability.

## Original defect description
GET /v1/field exposes raw diagnostics; no auth scope is specified. It should be admin-only.

## Affected subsystem
S5 Vector Current / API Gateway

## Root cause
v1.0 added a diagnostics endpoint without an authorization model.

## Proposed correction
Scope GET /v1/field to admin role in gateway/routes.py and gateway/auth.py; non-admin callers receive 403; audit-log all admin field accesses.

## Implementation files
- `gateway/routes.py`
- `gateway/auth.py`

## Verification method

## Test identifier

## Status
implemented_unverified

Auth scoping is specified; not implemented or tested. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Existing integrations using /v1/field will break; needs a migration note.
