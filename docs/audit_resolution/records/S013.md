# S013 — Cosine disagreement on hidden states is a poor proxy for contradiction

- **Audit ID:** S013 (source issue #13)
- **Title:** Cosine disagreement on hidden states is a poor proxy for contradiction
- **Classification:** [MTH]
- **Severity:** medium
- **Severity rationale:** A bad disagreement metric drives wrong decomposition decisions.

## Original defect description
Pairwise disagreement D = 1 - cos(h_i, h_j) on hidden states is a poor proxy for semantic contradiction: orthogonal vectors can express the same meaning in unaligned representation spaces.

## Affected subsystem
S1 Chimera Gate

## Root cause
Geometric distance was conflated with semantic disagreement.

## Proposed correction
Replace with a learned contradiction scorer in stations/s01_chimera/discord.py: align hidden states via a projection head trained on contradiction-labeled pairs, then score disagreement in the aligned space with a calibrated threshold.

## Implementation files
- `stations/s01_chimera/discord.py`

## Verification method
pytest tests/unit/test_s01.py::test_discord_metric_calibrated

## Test identifier
tests/unit/test_s01.py::test_discord_metric_calibrated

## Status
scheduled

## Status justification
Requires a labeled contradiction dataset and projection-head training; scheduled. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
An uncalibrated replacement metric could be worse than cosine if trained on biased labels.
