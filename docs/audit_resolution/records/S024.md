# S024 — Sparse bridge attention every 6th block is static

- **Audit ID:** S024 (source issue #24)
- **Title:** Sparse bridge attention every 6th block is static
- **Classification:** [ALG]
- **Severity:** medium
- **Severity rationale:** Static attention patterns underperform on long, uneven contexts.

## Original defect description
'Sparse bridge attention every 6th block' — the attention pattern is static. True long-context handling requires dynamic attention (e.g., chunked prefix or streaming attention).

## Affected subsystem
S2 Sexagesimal Turn

## Root cause
The pattern was derived from the ring geometry (every 6th of 60) rather than from retrieval needs.

## Proposed correction
Replace with salience-driven dynamic bridge attention in stations/s02_turn/attention.py: bridge targets selected per query by a lightweight scorer, with the static 6th-block pattern kept only as a fallback.

## Implementation files
- `stations/s02_turn/attention.py`

## Verification method
pytest tests/unit/test_s02.py::test_bridge_attention_dynamic

## Test identifier
tests/unit/test_s02.py::test_bridge_attention_dynamic

## Status
scheduled

## Status justification
Dynamic attention is a research-level change; scheduled after the buffer rewrite. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Dynamic patterns are harder to verify; needs attention-pattern regression tests.
