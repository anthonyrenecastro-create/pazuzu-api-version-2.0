# S005 — No end-to-end latency budget across 12 stations

- **Audit ID:** S005 (source issue #5)
- **Title:** No end-to-end latency budget across 12 stations
- **Classification:** [PERF]
- **Severity:** medium
- **Severity rationale:** Compounding queueing delay can silently blow any SLO without a budget to measure against.

## Original defect description
No end-to-end latency budget summation is provided. Twelve stations with inter-station handoffs risk compounding queueing delays, especially if worker pool sizes are unbounded (Little's Law).

## Affected subsystem
Orchestration Pipeline

## Root cause
v1.0 specified per-station behavior without a global timing contract.

## Proposed correction
Publish a latency budget table in config/latency_budget.yaml (per-station p50/p99 allowances summing to the global SLO), enforce bounded worker pools with backpressure in pipeline/orchestrator.py, and emit per-handoff timing spans to pipeline/telemetry.py.

## Implementation files
- `config/latency_budget.yaml`
- `pipeline/orchestrator.py`
- `pipeline/telemetry.py`

## Verification method
pytest tests/integration/test_pipeline.py::test_handoffs_within_budget

## Test identifier
tests/integration/test_pipeline.py::test_handoffs_within_budget

## Status
scheduled

## Status justification
Budget table and bounded pools are planned v2.0 work; no implementation exists to test. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Without the budget, early v2.0 builds may accumulate unmeasured queueing delay before SLO violations are noticed.
