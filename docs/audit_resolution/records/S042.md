# S042 — Audit-distribution drift detection misses spaced-out Byzantine poisoning

- **Audit ID:** S042 (source issue #42)
- **Title:** Audit-distribution drift detection misses spaced-out Byzantine poisoning
- **Classification:** [ALG]
- **Severity:** high
- **Severity rationale:** A sophisticated attacker stays under the drift threshold indefinitely.

## Original defect description
'Watcher compromised/returning garbage' -> detected by audit-distribution drift. This requires a sustained window of bad outputs (Byzantine quorum). A sophisticated attack spaces out poison to stay under the drift threshold.

## Affected subsystem
S3 Dual Ward

## Root cause
Detection assumed naive, sustained misbehavior rather than adaptive adversaries.

## Proposed correction
Add multi-timescale anomaly detection in stations/s03_dual_ward/integrity.py: per-output likelihood scoring against the Watcher's historical distribution plus canary probes with known-good answers; any canary failure triggers immediate quarantine regardless of drift windows.
