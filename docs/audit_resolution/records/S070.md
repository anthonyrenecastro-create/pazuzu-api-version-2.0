# S070 — Low entropy on deterministic prompts misread as mode collapse

- **Audit ID:** S070 (source issue #70)
- **Title:** Low entropy on deterministic prompts misread as mode collapse
- **Classification:** [MTH]
- **Severity:** medium
- **Severity rationale:** The controller would corrupt factual answers by injecting randomness.

## Original defect description
Output-token entropy H_t = -Σp_i log p_i is computed over the vocabulary. Low entropy does not mean 'mode collapse' if the prompt is deterministic (e.g., 'What is 2+2?'). The controller will artificially inflate temperature on factual queries.

## Affected subsystem
S6 Thermodynamic Brake

## Root cause
Entropy was interpreted without conditioning on prompt determinism.

## Proposed correction
Condition the target entropy on prompt type in stations/s06_brake/controller.py: estimate prompt determinism (classifier or prompt prior) and lower H* accordingly; never inflate temperature when the low entropy is prompt-explained.
