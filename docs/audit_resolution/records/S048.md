# S048 — Speculative branches need 3-5x duplicate KV caches, unaccounted

- **Audit ID:** S048 (source issue #48)
- **Title:** Speculative branches need 3-5x duplicate KV caches, unaccounted
- **Classification:** [PERF]
- **Severity:** high
- **Severity rationale:** Unbudgeted 3-5x memory means the deployment cannot actually run the swarm.

## Original defect description
Speculative branches for early-exit consensus require duplicate KV caches; memory overhead is 3-5x, unaccounted for in deployment sizing.

## Affected subsystem
S4 Swarm Agreement

## Root cause
v1.0 counted branches but not their memory.

## Proposed correction
Add KV-cache sharing (prefix-shared pages across branches) in stations/s04_swarm/agreement.py and account branch memory explicitly in the deployment sizing doc (docs/capacity.md); cap branches by available memory at runtime.

## Implementation files
- `stations/s04_swarm/agreement.py`
- `docs/capacity.md`

## Verification method
pytest tests/unit/test_s04.py::test_branch_memory_capped

## Test identifier
tests/unit/test_s04.py::test_branch_memory_capped

## Status
scheduled

## Status justification
Cache sharing is a substantial engineering change; scheduled with capacity planning. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Without sharing, swarm is undeployable at the specified branch counts.
