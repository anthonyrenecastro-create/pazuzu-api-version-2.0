# S067 — Re-anchoring assumes archive blocks are topically relevant

- **Audit ID:** S067 (source issue #67)
- **Title:** Re-anchoring assumes archive blocks are topically relevant
- **Classification:** [ALG]
- **Severity:** low
- **Severity rationale:** Degrades correction quality in edge cases; usually the archive is relevant.

## Original defect description
Re-anchoring logic assumes S2 archive blocks are topically relevant; they might just be old system prompts.

## Affected subsystem
S5 Vector Current / S2 Sexagesimal Turn

## Root cause
The re-anchor heuristic did not check relevance before injecting.

## Proposed correction
Score archive-block relevance before injection in stations/s05_vector_current/station.py (cosine similarity to the current segment in the reduced subspace); skip blocks below threshold and fall back to a neutral anchor.
