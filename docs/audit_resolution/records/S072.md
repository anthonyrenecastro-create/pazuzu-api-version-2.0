# S072 — Anti-windup clip is post-hoc; true anti-windup needs back-calculation

- **Audit ID:** S072 (source issue #72)
- **Title:** Anti-windup clip is post-hoc; true anti-windup needs back-calculation
- **Classification:** [PERF]
- **Severity:** medium
- **Severity rationale:** Incomplete anti-windup lets the integrator wind up and overshoot.

## Original defect description
The anti-windup clip is applied post-hoc. True anti-windup requires back-calculation of the integral term; the spec is incomplete.

## Affected subsystem
S6 Thermodynamic Brake

## Root cause
The spec named anti-windup without implementing the mechanism.

## Proposed correction
Implement proper back-calculation anti-windup in stations/s06_brake/controller.py (conditional integration: freeze the integrator while the output is saturated), with saturation limits in config/sampling.yaml.

## Implementation files
- `stations/s06_brake/controller.py`
- `config/sampling.yaml`

## Verification method
pytest tests/unit/test_s06.py::test_antiwindup_back_calculation

## Test identifier

## Status
implemented_unverified

## Status justification
Back-calculation design is specified; not implemented or tested. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Saturation limits must be chosen carefully or the controller loses authority when it is needed most.
