# S030 — Rotation counter increment unit is undefined

- **Audit ID:** S030 (source issue #30)
- **Title:** Rotation counter increment unit is undefined
- **Classification:** [ALG]
- **Severity:** high
- **Severity rationale:** Per-request rotation can rotate a block mid-sentence, corrupting conversational coherence.

## Original defect description
Rotation counter k increments per what? Per request? Per token? If per request, a multi-turn chat rotates arbitrarily mid-sentence.

## Affected subsystem
S2 Sexagesimal Turn

## Root cause
The counter's unit was never defined, so its behavior is implementation-accidental.

## Proposed correction
Define rotation per committed macro-block (token-count based, 512 tokens) in stations/s02_turn/buffer.py; rotation never splits an in-flight turn — a turn boundary or explicit flush triggers the advance.

## Implementation files
- `stations/s02_turn/buffer.py`
- `docs/pipeline_semantics.md`

## Residual risk
