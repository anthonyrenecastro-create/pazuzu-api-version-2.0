# S047 — Medoid selection is O(N^2) over the embedding distance matrix

- **Audit ID:** S047 (source issue #47)
- **Title:** Medoid selection is O(N^2) over the embedding distance matrix
- **Classification:** [ALG]
- **Severity:** medium
- **Severity rationale:** Quadratic medoid cost scales badly as branch count or embedding size grows.

## Original defect description
Spawn 3-5 continuations -> medoid selection. Medoid computation is O(N^2) distance matrix; expensive for large embedding spaces.

## Affected subsystem
S4 Swarm Agreement

## Root cause
The exact medoid was specified without considering scaling.

## Proposed correction
Use an approximate medoid in stations/s04_swarm/medoid.py: sample-based or k-medoids++ seeding with early termination, plus a configurable branch cap; exact medoid retained as a debug option.

## Implementation files
- `stations/s04_swarm/medoid.py`

pytest tests/unit/test_s04.py::test_approximate_medoid_scales

## Status
implemented_unverified

## Status justification
Approximate medoid is designed; not implemented or tested. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Approximation can pick a different medoid than exact; bound the disagreement rate in tests.
