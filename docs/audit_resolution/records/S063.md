# S063 — Divergence is measured post-emission: correction, not prevention

- **Audit ID:** S063 (source issue #63)
- **Title:** Divergence is measured post-emission: correction, not prevention
- **Classification:** [ALG]
- **Severity:** high
- **Severity rationale:** The station's headline claim ('ruin prevented before it takes flight') is false.

## Original defect description
'Ruin prevented before it takes flight' — but the divergence is measured after emission (it is calculated on embeddings of emitted tokens). It is post-hoc correction, not prevention.

## Affected subsystem
S5 Vector Current

## Root cause
The formalism analyzed emitted tokens while claiming pre-emission intervention.

## Proposed correction
Correct the claim and the mechanism in stations/s05_vector_current/station.py and docs: S5 is a fast post-hoc corrector (it can revise or flag within the same turn), and true pre-emission prevention is assigned to the S3 hold gate (issue 36); docs no longer claim prevention.
