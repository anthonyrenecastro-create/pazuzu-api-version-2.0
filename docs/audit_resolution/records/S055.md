# S055 — Replay determinism impossible across heterogeneous GPU nodes

- **Audit ID:** S055 (source issue #55)
- **Title:** Replay determinism impossible across heterogeneous GPU nodes
- **Classification:** [ALG]
- **Severity:** medium
- **Severity rationale:** Promised determinism that hardware cannot deliver is a false guarantee.

## Original defect description
Replay determinism requires exact hardware floating-point equivalence (GPU non-determinism), which is impossible across different cluster nodes.

## Affected subsystem
S4 Swarm Agreement / API

## Root cause
v1.0 promised bit-exact replay without accounting for GPU floating-point variance.

## Proposed correction
Redefine the replay contract in docs/pipeline_semantics.md and gateway/routes.py: replay guarantees semantic equivalence within a tolerance (same medoid cluster, score deltas bounded), not bit-exactness; record hardware/firmware in the replay bundle.

## Implementation files
- `docs/pipeline_semantics.md`
- `gateway/routes.py`

## Residual risk
