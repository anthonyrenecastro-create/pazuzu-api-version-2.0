# S039 — Single regeneration with tightened temperature yields refusals

- **Audit ID:** S039 (source issue #39)
- **Title:** Single regeneration with tightened temperature yields refusals
- **Classification:** [ALG]
- **Severity:** medium
- **Severity rationale:** The recovery path degrades usefulness, trading one failure mode for another.

## Original defect description
'One regeneration with tightened temperature' — tightening temperature on an already-failed generation often leads to safe but unhelpful (refusal) outputs.

## Affected subsystem
S3 Dual Ward

## Root cause
The retry policy changed only the sampling temperature, not the guidance given to the model.

## Proposed correction
Replace the retry policy in stations/s03_dual_ward/retry.py: on failure, regenerate with the Watcher's axis feedback injected as revision instructions (targeted fix), not just lower temperature; cap at two attempts, then escalate to human review.

## Implementation files
- `stations/s03_dual_ward/retry.py`

## Status

## Status justification
Feedback-driven retry is designed; not implemented or tested. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Injecting watcher feedback can be gamed if the feedback text leaks into the user-visible output.
