# S010 — 'Quarantine' namespace collision between S3 handoff and S11 role

- **Audit ID:** S010 (source issue #10)
- **Title:** 'Quarantine' namespace collision between S3 handoff and S11 role
- **Classification:** [ARC]
- **Severity:** medium
- **Severity rationale:** Ambiguous 'quarantine' semantics risk routing failures to the wrong sink.

## Original defect description
The 'quarantine handoff' from S3 to S11 reads as if S11 is a dead-letter queue, but S11 is later defined as an active transformation (sanitize/isolate). The word 'quarantine' carries two meanings.

## Affected subsystem
S11 (Sanitize/Isolate) / Pipeline routing

## Root cause
The same term was reused for a routing destination and a processing semantic.

## Proposed correction
Rename the routing concept: S3 emits to a dead-letter sink (pipeline/sinks.py::dead_letter) while S11 is the sanitize/isolate transformation; docs/terminology.md reserves 'quarantine' for the S11 active transform only.

## Implementation files
- `pipeline/sinks.py`
- `stations/s11_isolate/station.py`
- `docs/terminology.md`

## Residual risk
