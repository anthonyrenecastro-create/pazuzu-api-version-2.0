# S033 — Summarizing oldest blocks needs an auxiliary model call (latency spike)

- **Audit ID:** S033 (source issue #33)
- **Title:** Summarizing oldest blocks needs an auxiliary model call (latency spike)
- **Classification:** [PERF]
- **Severity:** medium
- **Severity rationale:** Unbounded summarization latency on the rotation path creates p99 spikes.

## Original defect description
Summarizing the oldest blocks requires an auxiliary model call, adding massive latency spikes during context shifts.

## Affected subsystem
S2 Sexagesimal Turn

## Root cause
Summarization was placed on the synchronous rotation path.

## Proposed correction
Move summarization off the critical path in stations/s02_turn/archive.py: rotate first (cheap pointer advance), summarize asynchronously with a bounded worker pool; readers see a 'summary pending' state with the raw block still resident until the summary lands.

## Implementation files
- `stations/s02_turn/archive.py`

## Residual risk
