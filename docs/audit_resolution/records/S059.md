# S059 — Re-anchoring on divergence can frustrate legitimate topic pivots

- **Audit ID:** S059 (source issue #59)
- **Title:** Re-anchoring on divergence can frustrate legitimate topic pivots
- **Classification:** [ALG]
- **Severity:** medium
- **Severity rationale:** Over-eager correction fights the user instead of helping them.

## Original defect description
'Injecting top-3 archive blocks' on high divergence is a heuristic. If the divergence comes from a necessary pivot (e.g., the user asks to change subject), re-anchoring frustrates user intent.

## Affected subsystem
S5 Vector Current

## Root cause
All divergence was treated as error, with no distinction between drift and deliberate pivots.

## Proposed correction
Add intent detection before re-anchoring in stations/s05_vector_current/station.py: if the segment contains an explicit topic-shift signal (user request, discourse marker), suppress re-anchoring and re-baseline the trajectory instead.

## Implementation files
- `stations/s05_vector_current/station.py`

## Status justification
Intent-gated re-anchoring is designed; not implemented or tested. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Intent detection errors cut both ways: missed pivots frustrate users, false pivots let real drift through.
