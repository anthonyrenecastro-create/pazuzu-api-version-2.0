# S020 — No endpoint to force-route to a specific expert

- **Audit ID:** S020 (source issue #20)
- **Title:** No endpoint to force-route to a specific expert
- **Classification:** [API]
- **Severity:** medium
- **Severity rationale:** Without forced routing, A/B tests and debugging of individual experts are impossible.

## Original defect description
No endpoint exists to force-route to a specific expert for A/B testing or debugging.

## Affected subsystem
S1 Chimera Gate / API

## Root cause
v1.0 exposed no operator/debug surface for the router.

## Proposed correction
Add an admin-scoped override: POST /v1/debug/route with {expert_id, ttl} in gateway/routes.py, honored by stations/s01_chimera/router.py; every override is audit-logged.

## Implementation files
- `gateway/routes.py`
- `stations/s01_chimera/router.py`

## Verification method

## Test identifier

## Status

## Residual risk
