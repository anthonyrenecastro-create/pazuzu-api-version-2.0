# S043 — Failover violates the core intersection law ('Keeper speaks alone')

- **Audit ID:** S043 (source issue #43)
- **Title:** Failover violates the core intersection law ('Keeper speaks alone')
- **Classification:** [LOG]
- **Severity:** high
- **Severity rationale:** The failover design contradicts the system's foundational safety claim.

## Original defect description
The intersection rule claims 'only intersection is spoken', yet failover mode allows 'Keeper speaks alone'. The core law is violated by the failover design.

## Affected subsystem
S3 Dual Ward / Doctrine

## Root cause
Availability was prioritized over the safety invariant without acknowledging the contradiction.

## Proposed correction
Resolve the contradiction explicitly in docs/doctrine.md and stations/s03_dual_ward/failover.py: failover mode is a declared degraded regime with its own (weaker) published guarantees — it never claims intersection-law protection; responses carry the signed degraded attestation (issue 41).

- `docs/doctrine.md`
