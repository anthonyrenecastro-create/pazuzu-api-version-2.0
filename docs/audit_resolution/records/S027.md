# S027 — Retention probability assumes exponential (memoryless) decay

- **Audit ID:** S027 (source issue #27)
- **Title:** Retention probability assumes exponential (memoryless) decay
- **Classification:** [MTH]
- **Severity:** medium
- **Severity rationale:** Wrong decay model misallocates retention budget across the context.

## Original defect description
Retention probability R(k) = exp(-k/60 · λ) assumes exponential decay (memoryless). Human/LLM context forgetting follows a power law (recency effect).

## Affected subsystem
S2 Sexagesimal Turn

## Root cause
Exponential decay was chosen for analytic convenience, not empirical fit.

## Proposed correction
Replace with a fitted power-law retention model R(k) = (1 + k/k0)^-α in stations/s02_turn/retention.py, with α, k0 fit from measured recall curves and stored in config/context.yaml.

## Implementation files
- `stations/s02_turn/retention.py`
- `config/context.yaml`
