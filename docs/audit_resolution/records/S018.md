# S018 — Switch-Transformer auxiliary loss coefficient uncalibrated

- **Audit ID:** S018 (source issue #18)
- **Title:** Switch-Transformer auxiliary loss coefficient uncalibrated
- **Classification:** [MTH]
- **Severity:** low
- **Severity rationale:** A hyperparameter note; mis-tuning affects efficiency, not correctness.

## Original defect description
The Switch-Transformer auxiliary loss is mentioned, but its coefficient (typically 0.01) is highly sensitive and uncalibrated in the spec.

## Affected subsystem
S1 Chimera Gate

## Root cause
The spec named the loss without its tuning procedure.

## Proposed correction
Make the coefficient a tuned hyperparameter in config/training.yaml with a documented sweep procedure in docs/training.md; default 0.01 with a routing-collapse guard that raises the coefficient automatically.

## Implementation files
- `config/training.yaml`
- `docs/training.md`

## Verification method
pytest tests/unit/test_s01.py::test_aux_loss_coefficient_configurable

## Test identifier
tests/unit/test_s01.py::test_aux_loss_coefficient_configurable

## Status
scheduled

## Status justification
Tuning requires training runs that have not happened; scheduled with the training program. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Wrong coefficient wastes capacity; bounded by the automatic collapse guard.
