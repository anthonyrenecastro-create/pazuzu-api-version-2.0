# S031 — Ring closure vs cylinder topology for block 1/block 60

- **Audit ID:** S031 (source issue #31)
- **Title:** Ring closure vs cylinder topology for block 1/block 60
- **Classification:** [HST]
- **Severity:** low
- **Severity rationale:** Topology naming question; behavior is whatever the spec declares.

## Original defect description
Base-60 ring implies 360° closure: if context wraps, block 1 attends to block 60. Is that desired, or is block 1 'born' and block 60 'dying' (cylinder, not ring)?

## Affected subsystem
S2 Sexagesimal Turn / Terminology

## Root cause
The ring metaphor was never given a precise topology.

## Proposed correction
Documentary decision in docs/pipeline_semantics.md: the buffer is a cylinder (linear aging, oldest evicted, no wrap attention); the 'ring' name is retained as legacy terminology with the topology explicitly defined.
