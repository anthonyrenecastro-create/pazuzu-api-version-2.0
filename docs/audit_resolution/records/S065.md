- **Audit ID:** S065 (source issue #65)
- **Title:** No hierarchy defined when S5 drift and S10 fracture both trigger
- **Classification:** [LOG]
- **Severity:** medium
- **Severity rationale:** Two correctors acting on the same segment without precedence can fight each other.

## Original defect description
S5 corrects drift, S10 corrects fracture. No hierarchy is defined if both trigger on the same segment.

## Affected subsystem
S5 Vector Current / S10 / Pipeline

## Root cause
Overlapping station responsibilities were never ordered.

## Proposed correction
Define the correction precedence in pipeline/merge.py and docs/pipeline_semantics.md: fracture (S10) takes precedence over drift (S5) since structural breaks dominate gradual drift; both directives are logged and the suppressed one is recorded as such.
