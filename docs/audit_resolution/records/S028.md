# S028 — Retention probe is offline-only (needle-in-haystack)

- **Audit ID:** S028 (source issue #28)
- **Title:** Retention probe is offline-only (needle-in-haystack)
- **Classification:** [OBS]
- **Severity:** medium
- **Severity rationale:** Offline evals cannot detect live retention degradation in production.

## Original defect description
pazuzu_s2_retention_probe via needle-in-haystack is an offline eval; online probing (injecting synthetic facts and querying later) is needed for live metrics.

## Affected subsystem
S2 Sexagesimal Turn / Telemetry

## Root cause
v1.0 instrumented retention only in the lab, not in production.

## Proposed correction
Add an online prober in stations/s02_turn/probe.py: inject canary facts into a sample of live sessions, query them later, and export recall as pazuzu_s2_online_retention; canaries are tagged to exclude them from user-visible output.

## Implementation files
- `stations/s02_turn/probe.py`
- `pipeline/telemetry.py`

## Verification method
pytest tests/unit/test_s02.py::test_online_probe_canary_recall

## Test identifier
tests/unit/test_s02.py::test_online_probe_canary_recall

## Status
scheduled

## Status justification
Online probing touches live traffic; scheduled pending privacy/safety review of canary injection. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Canary leakage into user-visible output would be a correctness and trust incident; tagging must be airtight.
