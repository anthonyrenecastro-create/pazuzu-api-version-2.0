# S051 — Aligned-cluster scoring equates consensus with truth

- **Audit ID:** S051 (source issue #51)
- **Title:** Aligned-cluster scoring equates consensus with truth
- **Classification:** [MTH]
- **Severity:** medium
- **Severity rationale:** In adversarial domains the correct answer is the outlier; consensus scoring fails exactly where it matters.

## Original defect description
Aligned-cluster scoring assumes semantic truth equals consensus. In adversarial domains (e.g., math puzzles), the correct answer is often an outlier.

## Affected subsystem
S4 Swarm Agreement

## Root cause
Majority intuition was applied to domains where it does not hold.

## Proposed correction
Add a domain-aware scoring mode in stations/s04_swarm/agreement.py: for flagged adversarial domains (math, logic, code), score branches by verifiable checks (execution, proof sketch) instead of cluster size; document the mode switch in docs/pipeline_semantics.md.

## Implementation files
- `stations/s04_swarm/agreement.py`
- `docs/pipeline_semantics.md`

## Residual risk
Misclassified domains would apply the wrong scoring mode; the classifier needs its own evaluation.
