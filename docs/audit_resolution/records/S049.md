# S049 — 'Tie-break by Watcher score' couples S4 to S3, breaking parallelism

- **Audit ID:** S049 (source issue #49)
- **Title:** 'Tie-break by Watcher score' couples S4 to S3, breaking parallelism
- **Classification:** [ALG]
- **Severity:** high
- **Severity rationale:** A hidden S3 dependency in S4 destroys the parallel-stream architecture.

## Original defect description
'Tie-break by Watcher score' introduces an S3 dependency into S4, violating the stated parallelism of S4-S5/S7-S10.

## Affected subsystem
S4 Swarm Agreement / Pipeline

## Root cause
The tie-break reached across station boundaries for convenience.

## Proposed correction
Remove the cross-station dependency in stations/s04_swarm/agreement.py: ties break by internal swarm criteria (branch likelihood, self-consistency score); S3 scoring applies later in the pipeline as designed.

## Implementation files
- `stations/s04_swarm/agreement.py`
- `docs/pipeline_semantics.md`
