# S075 — Target entropy H* is static; ideal entropy is context-dependent

- **Audit ID:** S075 (source issue #75)
- **Title:** Target entropy H* is static; ideal entropy is context-dependent
- **Classification:** [MTH]
- **Severity:** medium
- **Severity rationale:** A single entropy target cannot serve both brainstorming and code generation.

## Original defect description
Target entropy H* is static. Ideal entropy is context-dependent (high for brainstorming, low for coding).

## Affected subsystem
S6 Thermodynamic Brake

## Root cause
The setpoint was treated as a constant rather than a schedule.

## Proposed correction
Make H* context-dependent in stations/s06_brake/controller.py: task-type classifier maps the request to a target band in config/sampling.yaml (e.g., creative high, factual low, code lowest).

## Implementation files
- `stations/s06_brake/controller.py`
- `config/sampling.yaml`

## Verification method
pytest tests/unit/test_s06.py::test_context_dependent_entropy_target

## Test identifier
tests/unit/test_s06.py::test_context_dependent_entropy_target

## Status
implemented_unverified

## Status justification
Context-dependent targets are designed; the classifier and bands are not built. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Task misclassification sets the wrong entropy target; the classifier needs its own accuracy bar.
