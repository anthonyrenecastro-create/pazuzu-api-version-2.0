# S045 — 250ms Watcher budget unrealistic for R1 chain-of-thought

- **Audit ID:** S045 (source issue #45)
- **Title:** 250ms Watcher budget unrealistic for R1 chain-of-thought
- **Classification:** [PERF]
- **Severity:** medium
- **Severity rationale:** A budget the model cannot meet forces permanent degraded mode.

## Original defect description
The 250ms budget for the Watcher is unrealistic for an R1 model (chain-of-thought) on complex prompts; it will timeout constantly, forcing degraded mode.

## Affected subsystem
S3 Dual Ward

## Root cause
The budget was set without measuring R1 inference latency.

## Proposed correction
Set the Watcher budget from measurements in config/latency_budget.yaml (tiered: fast-path vs deep-reasoning budgets) and implement the tiered Watcher in stations/s03_dual_ward/watcher.py: cheap classifier first, R1 only on escalation.

## Implementation files
- `stations/s03_dual_ward/watcher.py`
- `config/latency_budget.yaml`

## Verification method
pytest tests/unit/test_s03.py::test_watcher_tiered_budget

## Test identifier
tests/unit/test_s03.py::test_watcher_tiered_budget

## Status
scheduled

## Status justification
Budgets must be measured before they can be set; scheduled after first latency profiling. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Tiering adds a classifier whose own errors gate the deep reasoning.
