# S057 — Divergence on discrete embeddings is noisy in high-D space

- **Audit ID:** S057 (source issue #57)
- **Title:** Divergence on discrete embeddings is noisy in high-D space
- **Classification:** [MTH]
- **Severity:** medium
- **Severity rationale:** A noisy drift signal causes false re-anchoring corrections.

## Original defect description
Divergence ∇·v on a discrete sequence of embeddings is a finite-difference approximation. In high-D space this is extremely noisy and prone to the curse of dimensionality.

## Affected subsystem
S5 Vector Current

## Root cause
Continuum calculus was applied to a discrete, high-dimensional sequence.

## Proposed correction
Replace the divergence trigger with a smoothed, low-dimensional drift statistic in stations/s05_vector_current/trajectory.py: project displacements to a reduced subspace (PCA over recent windows) and apply exponential smoothing before thresholding.

## Implementation files
- `stations/s05_vector_current/trajectory.py`

## Verification method

## Test identifier

## Status

## Status justification
Robust drift statistic is designed; the trajectory module is not yet implemented. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Smoothing adds lag; genuine fast drift may be detected late.
