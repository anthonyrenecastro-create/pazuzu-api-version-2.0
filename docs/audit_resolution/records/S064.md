# S064 — Embedding trajectory exposure aids adversarial prompt optimization

- **Audit ID:** S064 (source issue #64)
- **Title:** Embedding trajectory exposure aids adversarial prompt optimization
- **Classification:** [SEC]
- **Severity:** high
- **Severity rationale:** Internal geometry is a roadmap for black-box attackers.

## Original defect description
The embedding trajectory exposes internal semantic geometry to the API consumer, aiding adversarial prompt optimization (gradient-free black box).

## Affected subsystem
S5 Vector Current / API

## Root cause
v1.0 exposed raw diagnostics without considering their adversarial value.

## Proposed correction
Restrict trajectory diagnostics to admin scope in gateway/routes.py (see issue 66); the public API returns only coarse drift flags (none/elevated/high) with no coordinates, in stations/s05_vector_current/station.py.

## Implementation files
- `gateway/routes.py`
- `stations/s05_vector_current/station.py`
