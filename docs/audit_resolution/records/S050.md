# S050 — Replay endpoint leaks routing thresholds to binary-search attackers

- **Audit ID:** S050 (source issue #50)
- **Title:** Replay endpoint leaks routing thresholds to binary-search attackers
- **Classification:** [SEC]
- **Severity:** high
- **Severity rationale:** Reverse-engineered routing thresholds enable targeted expert-manipulation attacks.

## Original defect description
Seed + routing record exposed for POST /v1/replay allows attackers to reverse-engineer routing thresholds by binary searching for expert activation boundaries.

## Affected subsystem
S4 Swarm Agreement / API

## Root cause
v1.0 exposed internal routing internals for debuggability without an abuse model.

## Proposed correction
Restrict /v1/replay to admin scope, redact routing internals (return outcome + provenance, not raw gate activations) in gateway/routes.py, and rate-limit replay requests.

## Implementation files
- `gateway/routes.py`

## Verification method

## Residual risk
Legitimate debugging loses fidelity; provide a separate offline replay bundle for operators.
