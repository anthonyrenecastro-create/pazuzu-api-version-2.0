# S001 — Intersection rule assumes independent failure modes

- **Audit ID:** S001 (source issue #1)
- **Title:** Intersection rule assumes independent failure modes
- **Classification:** [LOG]
- **Severity:** high
- **Severity rationale:** If Keeper/Watcher failures are correlated, the entire dual-redundancy premise is void.

## Original defect description
The 'intersection rule' (only what Keeper AND Watcher agree on is spoken) treats the two LLM judges as independent. Because LLMs share training corpora and architectures, their failure modes are correlated, so 'agreement' is not evidence of correctness.

## Affected subsystem
S3 Dual Ward / Doctrine

## Root cause
Diversity assumption borrowed from classical fault-tolerant hardware, applied without evidence to LLM agents.

## Proposed correction
Replace the naive intersection with an independence-calibrated agreement gate in stations/s03_dual_ward/agreement.py: compute inter-judge agreement against a baseline correlation measured on a held-out probe set (pipeline/stats/judge_correlation.py), and require margin above baseline before treating agreement as validation.
