# S008 — No schema for merging streaming t-digests across replicas

- **Audit ID:** S008 (source issue #8)
- **Title:** No schema for merging streaming t-digests across replicas
- **Classification:** [OBS]
- **Severity:** medium
- **Severity rationale:** Without a merge schema, cross-replica p99 telemetry is not comparable.

## Original defect description
't-digests, EVT p99' are listed as telemetry, but no schema is provided for how streaming digests are merged across distributed pipeline replicas.

## Affected subsystem
Telemetry / Observability

## Root cause
v1.0 named the statistics without specifying the distributed aggregation protocol.

## Proposed correction
Define a digest envelope (centroid scale, compression, window, replica id, mergeable flag) in pipeline/telemetry.py and implement deterministic centroid merge in pipeline/stats/digest_merge.py; document in docs/telemetry.md.

## Implementation files
- `pipeline/telemetry.py`
- `pipeline/stats/digest_merge.py`
- `docs/telemetry.md`

## Verification method
pytest tests/unit/test_telemetry.py::test_digest_merge_is_associative

## Test identifier
tests/unit/test_telemetry.py::test_digest_merge_is_associative

## Status
implemented_unverified

## Status justification
Schema and merge function are specified but unimplemented and untested. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Associativity violations would silently corrupt fleet-wide percentile estimates.
