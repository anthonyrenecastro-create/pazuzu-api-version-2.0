# S052 — Spec claims both 'wait-for-all' and 'early-exit'

- **Audit ID:** S052 (source issue #52)
- **Title:** Spec claims both 'wait-for-all' and 'early-exit'
- **Classification:** [ALG]
- **Severity:** medium
- **Severity rationale:** Contradictory completion semantics make behavior unpredictable.

## Original defect description
'Wait-for-all' vs 'early-exit' — the spec claims both. Early exit implies non-determinism (fastest branch wins, not best).

## Affected subsystem
S4 Swarm Agreement

## Root cause
Two completion policies were described without choosing one.

## Proposed correction
Choose explicitly in stations/s04_swarm/agreement.py: wait-for-all with a deadline is the default (deterministic given the branch set); early-exit is an opt-in config flag (config/swarm.yaml) that is clearly marked non-deterministic.

## Implementation files
- `stations/s04_swarm/agreement.py`
- `config/swarm.yaml`

## Residual risk
Wait-for-all latency is bounded by the slowest branch; the deadline must be tuned.
