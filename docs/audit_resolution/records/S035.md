# S035 — Watcher 4-axis scores are uncalibrated LLM judgments

- **Audit ID:** S035 (source issue #35)
- **Title:** Watcher 4-axis scores are uncalibrated LLM judgments
- **Classification:** [ALG]
- **Severity:** high
- **Severity rationale:** Uncalibrated judge scores make the 0.75 gate arbitrary — the safety mechanism's core dial is meaningless.

## Original defect description
The Watcher scores 4 axes in [0,1]. How are these calibrated? LLM judges are notoriously miscalibrated (overconfident).

## Affected subsystem
S3 Dual Ward

## Root cause
v1.0 treated raw LLM scores as probabilities without any calibration step.

## Proposed correction
Add a calibration layer in stations/s03_dual_ward/scorer.py: isotonic/Platt calibration fit on human-labeled axis data, with per-axis calibration curves versioned in config/calibration/ and re-fit on a schedule.

## Implementation files
- `stations/s03_dual_ward/scorer.py`
- `config/calibration/`
- `pipeline/eval/calibrate.py`

## Verification method
pytest tests/unit/test_s03.py::test_axis_scores_calibrated

## Test identifier
tests/unit/test_s03.py::test_axis_scores_calibrated

## Status
scheduled

## Status justification
Calibration requires a human-labeled dataset that does not exist; scheduled. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Miscalibration persists until the label set ships; the 0.75 gate is arbitrary in the meantime.
