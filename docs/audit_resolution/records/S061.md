# S061 — Pairwise cross products assume orientation; embedding spaces are orientation-ambiguous

- **Audit ID:** S061 (source issue #61)
- **Title:** Pairwise cross products assume orientation; embedding spaces are orientation-ambiguous
- **Classification:** [MTH]
- **Severity:** medium
- **Severity rationale:** Sign-flip isomorphisms make orientation-based features meaningless.

## Original defect description
Pairwise cross products of consecutive displacements imply orientation. Embedding spaces are orientation-ambiguous (sign flips are isomorphic).

## Affected subsystem
S5 Vector Current

## Root cause
Another borrowing from 3D vector calculus that does not survive in embedding space.

## Proposed correction
Eliminate all orientation-dependent features in stations/s05_vector_current/trajectory.py; use only rotation-invariant statistics (norms of displacements, angles between consecutive displacements, which are sign-invariant).

- `stations/s05_vector_current/trajectory.py`
- `docs/formalism.md`
