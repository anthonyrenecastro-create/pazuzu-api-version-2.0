# S037 — Compromised Keeper can report high confidence to bypass deep reasoning

- **Audit ID:** S037 (source issue #37)
- **Title:** Compromised Keeper can report high confidence to bypass deep reasoning
- **Classification:** [SEC]
- **Severity:** high
- **Severity rationale:** A single compromised component defeats the entire dual-ward safety design.

## Original defect description
DeepSeek-R1 reasoning mode is triggered on 'low confidence' — but Grok (the Keeper) generates the confidence score. A compromised Keeper reports high confidence to bypass the Watcher's deep reasoning.

## Affected subsystem
S3 Dual Ward

## Root cause
The trigger for scrutiny is produced by the party being scrutinized — a self-grading loop.

## Proposed correction
Decouple the trigger in stations/s03_dual_ward/gate.py: deep-reasoning escalation is decided by an independent risk model (input features + output entropy + anomaly signals), never by the Keeper's self-reported confidence.

## Implementation files
- `stations/s03_dual_ward/gate.py`
- `stations/s03_dual_ward/risk.py`

## Verification method
pytest tests/unit/test_s03.py::test_escalation_ignores_keeper_confidence

## Test identifier

## Status
implemented_unverified

## Status justification
Decoupled escalation is designed; the independent risk model is not built or tested. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
The independent risk model is itself attackable; defense-in-depth (rate limits, anomaly alerts) still needed.
