# S069 — PD controller derivative term on discrete entropy causes hunting

- **Audit ID:** S069 (source issue #69)
- **Title:** PD controller derivative term on discrete entropy causes hunting
- **Classification:** [ALG]
- **Severity:** medium
- **Severity rationale:** Temperature oscillations directly degrade output quality.

## Original defect description
PD controller T_{t+1} = T_t exp[-κ_e(H_t - H*) - κ_d Ḣ_t] — the derivative term Ḣ_t on discrete entropy is highly volatile and will cause temperature oscillations ('hunting').

## Affected subsystem
S6 Thermodynamic Brake

## Root cause
A continuous-time PD design was discretized without filtering the derivative.

## Proposed correction
Filter the derivative in stations/s06_brake/controller.py: use a smoothed derivative (exponential moving average of ΔH) with a deadband, or drop the D term to a PI controller; gains documented in config/sampling.yaml.

## Implementation files
- `stations/s06_brake/controller.py`
- `config/sampling.yaml`

## Verification method

## Status justification
Filtered-derivative design is specified; the controller is not yet implemented. The supplied source references 'eight fatal defects' but does not enumerate which of the 144 issues are fatal; therefore no fatal status is assigned anywhere in this registry.

## Residual risk
Over-filtering the derivative slows response to genuine entropy spikes.
